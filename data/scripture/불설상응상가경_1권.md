# 불설상응상가경(佛說相應相可經)

**서진(西晉) 사문(沙門) 법거(法炬) 한역 | 현대 한국어 신역**

---

부처님께서 사위국(舍衛國)에 계시면서 여러 비구들을 부르시니, 비구들이 곧 나아왔다.

부처님께서 비구들에게 말씀하시자, 비구들은 "예, 부처님의 말씀을 따르겠습니다"라고 대답하였다.

부처님께서 이렇게 말씀하셨다.

"들음이 없는 이는 들음이 없는 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

많이 들은 이는 많이 들은 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

음욕(婬欲)을 탐하는 이는 음욕을 탐하는 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

음욕을 탐하지 않는 이는 음욕을 탐하지 않는 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

성내는 이는 성내는 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

성내지 않는 이는 성내지 않는 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

어리석은 이는 어리석은 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

지혜로운 이는 지혜로운 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

보시(布施)하는 이는 보시하는 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

인색하고 탐욕스러운 이는 인색하고 탐욕스러운 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

욕심이 적은 이는 욕심이 적은 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

욕심이 많은 이는 욕심이 많은 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

계율(戒律)을 지키지 않는 이는 계율을 지키지 않는 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

계율을 지키는 이는 계율을 지키는 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

베풀기를 어렵게 여기는 이는 베풀기를 어렵게 여기는 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

베풀기를 쉽게 여기는 이는 베풀기를 쉽게 여기는 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

만족할 줄 모르는 이는 만족할 줄 모르는 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

만족할 줄 아는 이는 만족할 줄 아는 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

자신을 다스리지 못하는 이는 자신을 다스리지 못하는 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다.

자신을 잘 다스리는 이는 자신을 잘 다스리는 이끼리 서로 무리를 짓고, 서로 모이고, 서로 응하고, 서로 어울린다."

부처님께서 다시 말씀하셨다.

"비구들이여, 이러하니 지혜로운 사람이라면 마땅히 이 인연(因緣)을 잘 분별하여, 행할 만한 것은 행하고 행하지 말아야 할 것은 행하지 말아야 한다."

부처님께서 이렇게 말씀하시니, 비구들은 받들어 행하고 마음에 깊이 새겼다.

---

*계묘년(癸卯歲)에 고려국(高麗國) 대장도감(大藏都監)에서 칙명을 받들어 조조(雕造)하다.*
