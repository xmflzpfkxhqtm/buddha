# 대방광불화엄경(大方廣佛華嚴經) 제56권

**이세간품(離世間品) 제38 — 네 번째**

우전국(于闐國) 삼장(三藏) 실차난타(實叉難陀) 한역 | 현대 한국어 신역

---

### 5) 십회향(十廻向)을 답함 ②

"불자여,

보살마하살(菩薩摩訶薩)에게는 열 가지 걸림없는 작용(無礙用)이 있습니다.

무엇이 열인가 하면,

중생에 걸림없는 작용,

국토에 걸림없는 작용,

법에 걸림없는 작용,

몸에 걸림없는 작용,

원(願)에 걸림없는 작용,

경계에 걸림없는 작용,

지혜에 걸림없는 작용,

신통에 걸림없는 작용,

신통한 힘에 걸림없는 작용,

힘에 걸림없는 작용입니다.

불자여,

보살마하살의 중생에 걸림없는 작용이란 어떠한 것인가?

불자여,

보살마하살에게는 열 가지 중생에 걸림없는 작용이 있습니다.

무엇이 열인가 하면,

일체 중생에 중생이 없음을 아는 걸림없는 작용,

일체 중생이 오직 생각으로 유지될 뿐임을 아는 걸림없는 작용,

일체 중생을 위하여 법을 설할 때 한 번도 때를 놓치지 않는 걸림없는 작용,

일체 중생계를 두루 변화하여 나타내는 걸림없는 작용,

일체 중생을 한 털 끝 안에 두어도 비좁지 않은 걸림없는 작용,

일체 중생에게 다른 방향의 모든 세계를 나타내어 다 볼 수 있게 하는 걸림없는 작용,

일체 중생에게 제석(帝釋)·범천(梵天)·사천왕(四天王) 등 하늘의 몸을 나타내는 걸림없는 작용,

일체 중생에게 성문(聲聞)과 벽지불(辟支佛)의 고요한 위의(威儀)를 나타내는 걸림없는 작용,

일체 중생에게 보살의 행(行)을 나타내는 걸림없는 작용,

일체 중생에게 모든 부처님의 색신(色身) 상호(相好)와 일체 지혜의 힘과 정등각(正等覺) 이룸을 나타내는 걸림없는 작용,

이것이 열입니다.

불자여,

보살마하살에게는 열 가지 국토에 걸림없는 작용이 있습니다.

무엇이 열인가 하면,

모든 세계로 하나의 세계를 만드는 걸림없는 작용,

모든 세계를 하나의 털구멍 속에 넣는 걸림없는 작용,

모든 세계가 다함이 없음을 아는 걸림없는 작용,

하나의 몸이 가부좌(跏趺坐)하여 모든 세계에 가득하는 걸림없는 작용,

하나의 몸 안에 모든 세계를 나타내는 걸림없는 작용,

모든 세계를 진동시키면서도 중생들을 두렵게 하지 않는 걸림없는 작용,

모든 세계의 장엄거리로 하나의 세계를 장엄하는 걸림없는 작용,

하나의 세계의 장엄거리로 모든 세계를 장엄하는 걸림없는 작용,

하나의 여래와 하나의 대중으로써 모든 부처님 세계에 두루하게 중생을 나타내는 걸림없는 작용,

온갖 소(小)세계·중(中)세계·대(大)세계·넓은 세계·깊은 세계·위로 향한 세계·뒤집힌 세계·기울어진 세계·반듯한 세계가 여러 방향의 그물에 두루하여 한량없이 차별하며,

이것을 일체 중생에게 널리 보이는 걸림없는 작용,

이것이 열입니다.

불자여,

보살마하살에게는 열 가지 법에 걸림없는 작용이 있습니다.

무엇이 열인가 하면,

모든 법이 하나의 법에 들어가고 하나의 법이 모든 법에 들어가되 중생의 마음과 이해에 어긋나지 않는 걸림없는 작용,

반야바라밀(般若波羅蜜)로부터 모든 법을 내어 다른 이에게 설명하여 모두 깨닫게 하는 걸림없는 작용,

모든 법이 문자(文字)를 여읜 줄을 알면서도 중생으로 하여금 다 깨달아 들어가게 하는 걸림없는 작용,

모든 법이 하나의 모양에 들어감을 알면서도 한량없는 법의 모양을 연설(演說)하는 걸림없는 작용,

모든 법이 언설(言說)을 여읜 줄을 알면서도 다른 이에게 가없는 법문을 연설하는 걸림없는 작용,

모든 법에 넓은 문의 글자 바퀴(普門字輪)를 잘 굴리는 걸림없는 작용,

모든 법을 하나의 법문에 넣어도 서로 어긋나지 않아서 말할 수 없는 겁(劫) 동안 말하여도 다하지 않는 걸림없는 작용,

모든 법이 다 불법(佛法)에 들어가서 중생들로 하여금 알게 하는 걸림없는 작용,

모든 법이 가이없음을 아는 걸림없는 작용,

모든 법에 장애의 끝이 없음이 환(幻)의 그물처럼 한량없이 차별함을 알고 한량없는 겁 동안 중생에게 말하여도 다할 수 없는 걸림없는 작용,

이것이 열입니다.

불자여,

보살마하살에게는 열 가지 몸에 걸림없는 작용이 있습니다.

무엇이 열인가 하면,

모든 중생의 몸을 자기의 몸 안에 넣는 걸림없는 작용,

자기의 몸을 모든 중생의 몸 안에 넣는 걸림없는 작용,

모든 부처님의 몸을 하나의 부처님 몸 안에 넣는 걸림없는 작용,

하나의 부처님 몸을 모든 부처님의 몸 안에 넣는 걸림없는 작용,

모든 세계를 자기의 몸 안에 넣는 걸림없는 작용,

하나의 몸으로 일체 삼세(三世)의 법에 가득하여 중생을 나타내는 걸림없는 작용,

하나의 몸 안에 가없는 몸을 나타내어 삼매(三昧)에 드는 걸림없는 작용,

하나의 몸 안에 중생의 수효와 같은 몸을 나타내어 바른 깨달음을 이루는 걸림없는 작용,

모든 중생의 몸 안에 하나의 중생 몸을 나타내고 하나의 중생 몸 안에 모든 중생의 몸을 나타내는 걸림없는 작용,

모든 중생의 몸 안에 법신(法身)을 나타내고 법신 안에 모든 중생의 몸을 나타내는 걸림없는 작용,

이것이 열입니다.

불자여,

보살마하살에게는 열 가지 원(願)에 걸림없는 작용이 있습니다.

무엇이 열인가 하면,

모든 보살의 원을 자기의 원으로 삼는 걸림없는 작용,

모든 부처님이 보리(菩提)를 이루신 서원의 힘으로 자기가 정각(正覺) 이룸을 나타내는 걸림없는 작용,

교화할 중생을 따라서 스스로 아뇩다라삼먁삼보리(阿耨多羅三藐三菩提)를 이루는 걸림없는 작용,

온갖 가없는 겁에 큰 서원이 끊어지지 않는 걸림없는 작용,

식신(識身)을 여의고 지신(智身)에 집착하지 않으면서 자재한 원으로 모든 몸을 나타내는 걸림없는 작용,

자기 몸을 버려서 남의 소원을 만족케 하는 걸림없는 작용,

일체 중생을 두루 교화하되 큰 서원을 버리지 않는 걸림없는 작용,

모든 겁에서 보살의 행을 행하되 큰 서원이 끊이지 않는 걸림없는 작용,

하나의 털구멍에서 정각을 이루면서 원력(願力)으로 모든 부처님 국토에 두루하며 말할 수 없이 말할 수 없는 세계에서 낱낱 중생을 위하여서도 그렇게 나타내는 걸림없는 작용,

하나의 구절 법을 말하여 모든 법계에 가득하게 큰 바른 법의 구름을 일으키고 해탈의 번갯빛을 비추며 참된 법의 우렛소리를 울리고 감로(甘露)의 비를 내려 큰 서원의 힘으로 모든 중생 세계를 흡족케 하는 걸림없는 작용,

이것이 열입니다.

불자여,

보살마하살에게는 열 가지 경계에 걸림없는 작용이 있습니다.

무엇이 열인가 하면,

법계(法界)의 경계에 있으면서 중생의 경계를 버리지 않는 걸림없는 작용,

부처의 경계에 있으면서 마(魔)의 경계를 버리지 않는 걸림없는 작용,

열반(涅槃)의 경계에 있으면서 생사(生死)의 경계를 버리지 않는 걸림없는 작용,

일체지(一切智)의 경계에 들어가서 보살 종성(種性)의 경계를 끊지 않는 걸림없는 작용,

고요한 경계에 머물면서도 산란한 경계를 버리지 않는 걸림없는 작용,

감도 없고 옴도 없고 희론(戲論)도 없고 형상도 없고 자체도 없고 언설도 없어 허공과 같은 경계에 머물면서도 일체 중생의 희론 경계를 버리지 않는 걸림없는 작용,

모든 힘과 해탈의 경계에 있으면서도 모든 방소(方所)의 경계를 버리지 않는 걸림없는 작용,

중생의 끝없는 경계에 들어가도 일체 중생 교화하기를 버리지 않는 걸림없는 작용,

선정(禪定)·해탈(解脫)·신통(神通)·지혜(智慧)·고요한 경계에 머물면서도 일부러 모든 세계에 태어남을 버리지 않는 걸림없는 작용,

여래의 모든 행으로 장엄된 정각(正覺)의 경계에 머물면서 모든 성문과 벽지불의 고요한 위의를 나타내는 걸림없는 작용,

이것이 열입니다.

불자여,

보살마하살에게는 열 가지 지혜에 걸림없는 작용이 있습니다.

무엇이 열인가 하면,

다함 없는 변재(辯才)의 걸림없는 작용,

일체를 모두 지니고 잊지 않는 걸림없는 작용,

일체 중생의 근기(根機)를 결정적으로 알고 결정적으로 말하는 걸림없는 작용,

한 순간에 걸림없는 지혜로 일체 중생의 마음의 움직임을 아는 걸림없는 작용,

일체 중생의 욕락(欲樂)과 수면(隨眠)과 습기(習氣)와 번뇌의 병을 알고 알맞게 약을 주는 걸림없는 작용,

한 순간에 여래의 십력(十力)에 능히 드는 걸림없는 작용,

걸림없는 지혜로 삼세의 모든 겁과 그 속의 중생을 아는 걸림없는 작용,

순간순간마다 정각을 이루어 중생에게 보이되 끊어지지 않는 걸림없는 작용,

하나의 중생의 생각에서 일체 중생의 업(業)을 아는 걸림없는 작용,

하나의 중생의 음성에서 일체 중생의 말을 이해하는 걸림없는 작용,

이것이 열입니다.

불자여,

보살마하살에게는 열 가지 신통에 걸림없는 작용이 있습니다.

무엇이 열인가 하면,

하나의 몸 안에 모든 세계의 몸을 나타내는 걸림없는 작용,

하나의 부처님 대중 모임에서 모든 부처님 대중 모임에서 설하시는 법을 듣는 걸림없는 작용,

하나의 중생의 생각 속에서 말할 수 없는 위없는 보리를 이루고 일체 중생의 마음을 열리게 하는 걸림없는 작용,

하나의 음성으로 모든 세계의 차별한 음성을 나타내어 여러 중생이 각각 알아듣게 하는 걸림없는 작용,

한 생각 안에 지나간 세상의 모든 겁에 있었던 업(業)과 과보(果報)의 갖가지 차별을 여러 중생이 모두 알고 보게 하는 걸림없는 작용,

하나의 티끌 속에서 광대한 세계의 한량없는 장엄을 내는 걸림없는 작용,

모든 세계로 하여금 장엄을 구족하게 하는 걸림없는 작용,

모든 삼세에 두루 들어가는 걸림없는 작용,

큰 법의 광명을 놓아 모든 부처님의 보리와 중생의 행과 원을 나타내는 걸림없는 작용,

모든 하늘·용(龍)·야차(夜叉)·건달바(乾闥婆)·아수라(阿修羅)·가루라(迦樓羅)·

긴나라(緊那羅)·마후라가(摩睺羅伽)·제석(帝釋)·범천(梵天)·호세천(護世天)·성문·

독각·보살과 여래의 십력과 보살의 선근(善根)을 잘 수호하는 걸림없는 작용,

이것이 열입니다.

만약 보살들이 이 걸림없는 작용을 얻으면 능히 모든 불법에 두루 들어갈 수 있습니다.

불자여,

보살마하살에게는 열 가지 신통한 힘에 걸림없는 작용이 있습니다.

무엇이 열인가 하면,

말할 수 없이 많은 세계를 하나의 티끌 속에 두는 걸림없는 작용,

하나의 티끌 속에 법계와 같은 모든 세계를 나타내는 걸림없는 작용,

온갖 큰 바닷물을 하나의 털구멍에 넣어 시방세계를 돌아다니면서도 중생을 불편하게 하지 않는 걸림없는 작용,

말할 수 없이 많은 세계를 자기 몸 속에 넣어서 모든 신통한 일을 보이는 걸림없는 작용,

하나의 털로써 셀 수 없는 금강위산(金剛圍山)을 얽어매어 모든 세계를 돌아다니면서도 중생들로 하여금 두려운 마음을 내지 않게 하는 걸림없는 작용,

말할 수 없는 겁으로 하나의 겁을 만들고 하나의 겁으로 말할 수 없는 겁을 만들며 그 가운데 이루어지고 무너지는 차별을 나타내면서도 중생들의 마음을 두렵게 하지 않는 걸림없는 작용,

모든 세계에서 수재(水災)·화재(火災)·풍재(風災)의 갖가지 파괴를 나타내면서도 중생을 괴롭히지 않는 걸림없는 작용,

모든 세계가 수재·화재·풍재로 무너질 때 모든 중생들의 살림살이를 보호하여 파괴되지 않게 하는 걸림없는 작용,

한 손으로 부사의(不思議)한 세계를 들어 말할 수 없는 세계 밖에 던져도 중생들을 놀라지 않게 하는 걸림없는 작용,

장엄하는 결정한 이해이니 갖가지 장엄을 내기 때문이며,

넓고 큰 결정한 이해이니 마음이 잠깐도 용렬하지 않기 때문이며,

고요한 결정한 이해이니 매우 깊은 법의 성품에 들어가기 때문이며,

두루 퍼지는 결정한 이해이니 내는 마음이 미치지 않는 데가 없기 때문이며,

능히 감당하는 결정한 이해이니 부처님의 힘으로 가지(加持)함을 받기 때문이며,

견고한 결정한 이해이니 모든 마군의 업을 꺾어 버리기 때문이며,

밝게 판단하는 결정한 이해이니 모든 업과 과보를 알기 때문이며,

앞에 나타난 결정한 이해이니 마음대로 신통을 나타내기 때문이며,

이어 높이는(紹隆) 결정한 이해이니 모든 부처님 처소에서 수기(授記)를 얻기 때문이며,

자재한 결정한 이해이니 마음대로 때를 따라 성불하기 때문입니다.

이것이 열이니,

만약 보살들이 이 법에 편안히 머물면 여래의 위없는 결정한 이해를 얻습니다.

모든 세계가 하나의 여래의 몸과 하나의 연화좌에 다 두루함을 알고,

모든 세계가 다 허공과 같음을 알고,

모든 세계가 부처님의 장엄을 갖춤을 알고,

모든 세계에 보살이 가득함을 알고,

모든 세계가 하나의 털구멍에 들어감을 알고,

모든 세계가 하나의 중생의 몸에 들어감을 알고,

모든 세계가 하나의 부처님 보리수와 하나의 부처님 도량에 다 두루함을 알고,

모든 세계에 하나의 음성이 두루하여 여러 중생들이 제각기 알아듣고 마음에 환희합니다.

이것이 열이니,

만약 보살들이 이 법에 편안히 머물면 여래의 위없는 불찰(佛刹)의 넓고 큰 결정한 이해를 얻습니다.

불자여,

무엇이 열인가 하면,

모든 중생계의 본래 성품이 실답지 않음을 알며,

모든 중생계가 하나의 중생 몸에 들어감을 알며,

모든 중생계가 다 보살의 몸에 들어감을 알며,

모든 중생계가 다 여래장(如來藏)에 들어감을 알며,

하나의 중생 몸이 모든 중생계에 두루 들어감을 알며,

모든 중생계가 다 불법(佛法)의 그릇이 될 것을 알며,

모든 중생계가 그 욕망을 따라 제석·범천·사천왕의 몸을 나타냄을 알며,

모든 중생계가 그 욕망을 따라 성문·독각의 고요한 위의를 나타냄을 알며,

모든 중생계가 보살의 공덕으로 장엄한 몸을 나타냄을 알며,

모든 중생계가 여래의 훌륭한 상호와 고요한 위의를 나타내어 중생들을 깨우침을 압니다.

이것이 열이니,

만약 보살들이 이 법에 편안히 머물면 여래의 위없는 큰 위력의 결정한 이해를 얻습니다."
